# 日报格式（贴给用户的就是它，不要包壳）

## 硬约束

- **≤20 行**，决策优先，扫读友好
- 开头一行给"结论/今天最该知道的一件事"
- 一律**北京时间**；提到赛事日程用「10/18（周日）」
- 每条情报必须带**来源层级**：`官方` / `媒体` / `自媒体(B站/公众号)` / `转述`
- 数字带年份：今年数字 vs 往年参考要分开（例：2025 年 350 个车位）
- 不报战报；不重复已告知内容（脚本已去重，只有"必含板块"每天出现）

## 模板 A：有新增（常规日）

```
🎾 上海大师赛·决赛日攻略雷达 | 10月X日（距 10/18 决赛还有 N 天）

📌 今天最该知道：<一句话，例：官方今年新增 3 条接驳专线，自驾停车仍未开放预约>

🅿️ 停车/自驾
- <新增情报，带来源>（媒体｜本地宝）
- <往年参考要标年份>

🚇 往返
- <接驳车/地铁末班/打车点 的新变化>

🍜 吃饭·周边（仅在今天轮到该维度或有新料时出现）
- <情报>

🌦 天气（10/18 决赛日，逐时见下）
- <出行结论：带不带雨具、穿什么、几点天黑>
- 参考性：距今天 N 天，≥7 天仅趋势

🔎 其他新发现（各一行，无则省略）
- <B站视频/公众号文章标题 + 一句它讲什么>

🎒 出门前清单（T-3 内才出现，逐日收敛）
- □ <例：证件 > □ <例：雨具 > □ <例：提前 40 分钟到 2 号门>

————
本期新增 N 条（扫描 M 条 / 去重跳过 K 条）；源状态：<如有被限流写"百度本次被限流，已用 web_search 补"；无异常则省略>
```

## 模板 B：零新增（多数比赛日会是这个）

```
🎾 上海大师赛·攻略雷达 | 10月X日（距决赛 N 天）

今天没有新的实操情报（第三方讨论多为赛果/签表，与你现场体验无关）。

🌦 决赛日天气（10/18）：<一行结论>（距今天 N 天，仅趋势）
🎒 已知要点回顾（择要 1-2 条，轮换，不重复昨天讲过的）：
- <例：网约车在 6 号门（中青路×元江路），出租车在 2 号门>

剩余 N 天，我会继续盯着；有变化第一时间报。
```

## 决赛日（10/18）当天版

额外把这三件事顶到最前：
1. **几点出门 / 走哪条路**（结合天气与选定的交通方式给一个建议时间）
2. **入场门与证件**（2 号门出租车、6 号门网约车、观众入口闸机刷证）
3. **散场策略**（接驳车/打车点/预计出库高峰）

## 措辞纪律

- 用大白话，不用"赋能/闭环/生态"这类词
- 不确定就写"待核实"，不要含糊带过
- 小红书/微博内容只能标「转述」，且注明"未见全文"
