## 二、抓取纪律（踩过的坑）

1. **同名赛事污染是第一大坑**：搜「上海大师赛」会同时命中 **网球 / 斯诺克 / 电竞（CS、LOL）**。命令里的 `-斯诺克` 排除**无效**，必须结果后处理：
   - 黑名单（命中即丢）：`斯诺克 snooker 奥沙利文 丁俊晖 特鲁姆普 塞尔比 斯佳辉 国锦赛 台球 九球`
   - 电竞/其他（命中即丢）：`手枪局 电竞 JDG CS2 LPL 英雄联盟 王者荣耀 耐力赛 摩托 赛车`
   - 硬门槛：必须命中 `网球/大师赛/旗忠/劳力士/ATP` 之一
2. **`site:` 操作符在本机 web_search 后端无效**（返回 0 条或不相关）：不要靠 `site:xiaohongshu.com` 去抓小红书，白费。
3. **B站搜索页是 JS 渲染但 HTML 里带完整卡片**：标准库即可，无需 Playwright；解析务必用 `info--tit` 的 `title` 属性，直接抓 `<a>` 文本会抓到"664 0 02:30"这种播放量。
4. **限流应对**：脚本已被设计成「每天只跑 核心 2 组 + 轮换 1 组」（6 个关键词 × 3 源 = 18 请求），比全量少 2/3。若脚本报 `百度 安全验证` / `搜狗 验证码`：
   - **不要重试轰炸**（会延长冷却）；
   - 改用你自己的 `web_search` 补一轮（这正是 web_search 的强项：不吃验证码，且能拿到媒体/本地宝）；
   - 连续 2 天以上被限流才在报告里提一句（单日偶发不报，避免噪声）。
5. **公众号/百度返回的是跳转链接**（含时效 token）：报告里的链接可能过期，别承诺"点开就是原文"。
6. **抓不到 ≠ 不存在**：小红书上的实操攻略确实多，本技能拿不到正文。报告里若引用小红书内容，必须来自 web_search 的**摘要**，并标注「转述，未见全文」。
