# 飞书简报模板（200–400 字，正常也发）

```text
【serp_news 日巡检｜业务日期 YYYY-MM-DD】
总体：正常 / 关注 / 异常 / 监测受阻
数据：共 N 条，较七日基线 ±X%；高分 N 条。
主题：产出情况与明显波动。
模型：评分缺失 N 条，摘要候选 N 条/完成 N 条；抽检 N 条，发现 N 项问题。
官网：官网来源 N 条；数据覆盖结论。
重点：最多两项需要处理的问题，附必要记录 ID。
边界：依据数据库及必要的公开网页检查，未核验服务器执行日志。
```

写法要求
- 没数据或样本不足的指标写「不可判断」，不用 0%/100% 填补。
- 官网零产出要附「未见更新 / 疑似漏采 / 无法核实」的实际结论，不能只发一个数字。
- 发现实质错误时给一条简短原文对照证据，别只说「质量不好」。
- 不发送大段全文、整库数据、口令。
- 重复检查有新发现时明确标注「更新」。
- 发送命令：
```bash
lark-cli im +messages-send --chat-id "$FEISHU_HOME_CHANNEL" --as bot --markdown "<简报>"
```
核对返回的消息 ID（`om_...`）后才说「已通知」；发送状态不明时不盲目重发。
