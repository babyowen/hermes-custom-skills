## 预测方法论

### 核心战略认知

> **高考命题紧扣教育部年度命题总要求，围绕国家关切和时代热点展开。**
> 根据教学〔2026〕1号，今年命题核心是**"融入科技前沿动态，浸润人文教育元素，加强项目式、探究式的真实情境问题设计"**——这是所有预测的顶层依据。
>
> 关于模拟考趋势：**与模拟题的主题方向可以趋同**。从历史数据看，高考不回避模拟考中出现的热点方向——同类热点话题完全可能在高考中再次出现（往年有先例）。因此追踪模拟考的目的是识别当前公认的热点方向，重点在于：思辨角度要推陈出新，而非机械绕开。
>
> ⚠️ **预测的核心原则**：紧扣教育部方向判断可考性，以思辨角度设计为重心，而非机械猜测具体题目。
>
> ### ⏰ 考前冲刺期视角切换（5月23日起）
>
> **距离高考仅剩2周，搜索/分析策略必须从「当周追踪」切换为「年度全景扫描」模式：**
>
> - **命题在3-4月已完成定稿**，命题组参考的是**过去一整年**的素材，而非最后一个月
> - 命题者视角=回顾全年→提炼最核心的3-5个时代命题→设计思辨角度
> - 因此：**不再追「本周刚发生」的事件**，转而**回看2025年6月至今的全年大势**
> - 重点判断：过去一年中哪些主题是**真正贯穿始终的**，哪些只是短期新闻
> - 像命题组那样**反复咀嚼、持续思考**全年素材中蕴含的思辨张力，而非每天追新
>
> ### 🎂 整数纪念年份视角（新增维度）
>
> **高考命题经常以重要事件的「整数周年」作为材料背景或思辨切入点。** 不只是10/50/100这些大周年，20、35、40、55、70等非整十的整数年也是高频选择：
> - 例：2019五四运动100周年→2020信息茧房（未直接考纪念但时代感强）；2021建党百年→2021强弱之变（毛泽东体育之效，间接关联）
> - **2025-2026年应关注的整数纪念年**需通过搜索系统性盘点，但已知的重要方向：
>   - **长征胜利90周年**（1936-2026）——已被多方标注，常见切入：走好新时代长征路
>   - **其他需要搜索发现的**：追查2025-2026年有哪些重大事件到达20/30/35/40/55/70/80/90/100周年
> - **操作方法**：在搜索中专门加入对「整数纪念年」的盘点，而非仅追踪当年新发生的事件

### 六重分析框架（原五重 + 整数纪念年）

```

② 教育部命题方向研判（首要步骤）
```

### 考后阶段（考试结束后的处理）

**高考语文考试结束后，预测系统进入收官阶段：**

1. **搜索验证真题**：搜索实际考题全文，确认2026年新高考I卷作文题
2. **方向对比复盘**：将实际考题与预测方向逐条对比，评估匹配度
3. **写入参考文件**：将实际考题全文+题型分析写入：
   - `references/历年作文题汇编.md` — 在年份标题处新增条目，更新底部数据统计表
   - `references/2026趋势分析与预测方向.md` — 更新主题演变脉络、关键规律表、添加后验分析
4. **更新SKILL.md关键规律表**：新增2026年条目到规律表中，修正模式的判断
5. **标记素材库**：在飞书三个文档顶部标注「⏹ 高考已结束」，停止更新
6. **删除cron定时任务**：使用 `hermes cron remove <job_id>` 删除定时任务
7. **生成最终复盘报告**：投递到飞书群，包含真题全文、预测对比、评分、核心经验总结

> ⚠️ 考后阶段 cron 不需要每天运行。如果 cron 在考试结束后被触发，执行上述复盘操作后自动删除 cron。

### 🛠️ Feishu导出文件的修改模式（安全操作路径）

Feishu导出的文件含有 `\"` 转义字符，patch 无法处理，必须用以下安全的 **execute_code 模式**：

```python
from hermes_tools import terminal

# Step 1: 用 terminal() 读取完整文件内容
result = terminal(command="cat ~/.hermes/skills/<skill>/references/<文件>.md", timeout=10)
lines = result["output"].split('\n')

# Step 2: 在 Python 中修改内容
for i, line in enumerate(lines):
    if '需要修改的内容' in line:
        lines[i] = line.replace('旧文本', '新文本')

# Step 3: 用 Python 的 open() 写回（不要用 write_file，open 避免转义干扰）
new_content = '\n'.join(lines)
with open('/home/ubuntu/.hermes/skills/<skill>/references/<文件>.md', 'w') as f:
    f.write(new_content)

# Step 4: 推送到飞书
terminal(command="cat <文件路径> | lark-cli docs +update --doc <token> --markdown - --mode overwrite", timeout=30)
```

⚠️ 绝对不要用 `patch` 修改 Feishu 导出的文件——引号转义会逐层恶化。
