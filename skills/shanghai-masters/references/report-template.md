# 日报格式（贴给用户的就是它，不要包壳）

## 硬约束

- **≤28 行**，决策优先、扫读友好；分块小标题（emoji + 短标题）
- 开头一行给「今天最该知道的一件事」的结论
- 一律**北京时间**；赛事日程写「10/18（周日）」
- 每条情报带**来源层级**：`官方` / `媒体` / `微博` / `B站` / `公众号` / `转述`
- 数字带年份：今年数字 vs 往年参考必须分开（例：2025 年 350 个车位）
- **不报每日战报比分流水与球星花絮**；赛况只报与"决赛走势"相关的（谁出局、剩哪些种子、决赛最可能谁对谁）
- 抓不到的渠道不许假装读到：小红书一律标「转述（未读正文）」

## 板块顺序（固定，无内容就整块省略）

```
🅿️ 自驾停车  →  🎒 可带·禁带  →  🏁 赛况走势  →  💬 大家在聊什么  →  🌦 决赛日天气  →  🔎 其他
```

## 模板 A：有新增（常规日，多数日）

```
🎾 上海大师赛·决赛日攻略雷达 | 10月X日（距 10/18 决赛还有 N 天）

📌 今天最该知道：<一句话结论，例：观众自驾停周边六区、元江路临时车位离 2 号门最近>

🅿️ 自驾停车
- **停哪条路最近**：<具体路段 + 离哪个门近 + 来源>
- **导航到哪**：<导航关键词/路口；别导哪个门>
- 兜底/满位时：<次级路段>（来源）
- 散场：<走法/预计出库高峰>（来源）

🎒 可带·禁带（只有清单有变化、或有用户点名的问题时才出现）
- **水杯**：<能/不能 + 依据>（来源）
- <新确认的一条>

🏁 赛况走势（只有新变化时出现）
- 已出局种子：<谁、止步轮次>（官方）
- 还剩：<种子清单或"前 N 号种子都在" >
- 决赛最可能：<A vs B>（推测，依据 = 签表位置/赔率/状态）

💬 大家在聊什么（各一句，标来源）
- 微博：<正文要点>（微博）
- 小红书：<标题要点>（转述，未读正文）
- B站/公众号：<标题 + 一句讲什么>

🌦 决赛日 10/18（周日）：<温度区间/降水/风/日落> → <穿什么、带不带雨具>
- 参考性：距今天 N 天（≥7 天仅趋势）

————
本期新增 N 条（扫描 M / 保留 K / 去重跳过 J）；<源异常只在连续 2 天以上时提>
```

## 模板 B：零新增（无新情报的日子）

```
🎾 上海大师赛·攻略雷达 | 10月X日（距 10/18 决赛还有 N 天）

今天没有新的实操情报。

🅿️ 自驾回顾（轮换讲，一天一条，不重复昨天）
- <例：导航"旗忠网球中心 2 号门"，观众唯一入口在元江路>

🏁 赛况：<已出局种子/剩余种子一句话>（官方）

🌦 决赛日 10/18（周日）：<一行结论>（距今天 N 天，仅趋势）

剩余 N 天，我继续盯着；有变化第一时间报。
```

## 决赛日（10/18）当天版

额外把这三件事顶到最前：
1. **几点出门 / 走哪条路**（结合天气给建议时间）
2. **停哪条路 + 入场门与证件**（2 号门在元江路；实名制刷证+人脸）
3. **散场策略**（走哪条路、几点走、预计出库高峰）

## 措辞纪律

- 大白话，不用"赋能/闭环/生态"这类词
- 不确定就写"待核实"，不含糊带过
- 往年数字必须标年份，不许写成今年事实
- 不写"已按流程生成""以上为简报"这类元话
