# 虎跳峡·哈巴雪山每日风险简报

> **v1.5 三条铁律**：①先过区域适用性闸门再动笔 ②颜色=风险信号，没风险不上色 ③温度只报 `temp_est` 海拔校正估算值。
> **本区定义**：虎跳峡镇 / 三坝乡 / 哈巴村 / 香格里拉市 / 迪庆州。

## 目标区域与海拔梯度（判断"上游产流→下游山洪"的关键）

| 点位 | 海拔 | 说明 |
|:--|:--|:--|
| 虎跳峡镇·上虎跳 | 1700-1900m | 金沙江河谷，低海拔参照 |
| 哈巴村（三坝乡） | 2650-2700m | 徒步起点 |
| 兰花坪·羊房牧场 | 3300-3600m | 高山牧场 |
| 黑海营地·垭口（尖山牧场同区） | 4100-4200m | 上游湖泊，**最高关注点（不登顶）** |
| 香格里拉 / 丽江市区 | 3280m / 2400m | 城市级参考（预警适用区） |

⚠️ 脚本 `grid_elevation_m` 是**模型网格高程≠实际海拔**（虎跳峡镇网格 3290m vs 实际 1800m），温度必须走 `temp_est`；河谷实况以中国天气网虎跳峡风景区页（10129130106A）交叉校验。

## 执行流程

**Step 1 读取注入数据（两腿交叉验证）**：cron 已运行合并脚本，注入 `{"open_meteo":…,"domestic_cma":…}`
- `open_meteo`（网格，**趋势参考非实测**）：各点位 `past24h/72h_sum_mm`、`days[].sum_mm/max_hourly_mm`、`short_intense_windows`(≥10mm/h)、`next24/48/72h_sum_mm`
- `open_meteo.points[*].temp_est`（**温度唯一来源**）：`today`（今日最低/最高+时间）、`windows_today_c`（清晨06-08/正午12-14/午后14-16/夜间20-23）、`days[]`（未来3天高低温）、`next3d_night_min_c`、`next72h_hours_below_0c`、`correction_c`——已按 6.5℃/1000m 从网格高程校到实际海拔，**只作估算并标注**
- `domestic_cma`（**官方优先**）：`stations[香格里拉/丽江].wc_obs.rain24h_mm`（站点实测24h雨量）、`now`、`daily`（官方逐日预报）、`warnings`（**官方预警全文 JSON**）
- **铁律**：网格与站点矛盾（局地强对流：网格26.5mm/站点0mm）→ **以官方实测+预警为准**并说明成因；某腿 `fetch_errors` → web_extract 直调补数（模板 references/sources.md）；两腿都挂才写"降水数据源暂不可用"

**Step 2 预警与突发扫描**（每条记录：级别/类型/发布时间/单位/影响区域）
0. 首选注入的 `domestic_cma.warnings`（覆盖香格里拉/丽江/迪庆/德钦/维西 5 城码）；同时 web_search 补查山洪/地灾省级预警与突发
1. **点开官方原文读全文**（5-8篇/源，多源交叉），禁止只看摘要；**未搜到就写"未检索到山洪/地灾省级预警"**（省厅级不走城市JSON，只有搜索通道）
2. 优先级：中央气象台/中国天气网 → 云南省气象台 → 迪庆州 → 香格里拉市 → 水利部+气象局山洪 → 自然资源部+气象局地灾 → 应急/交通 → 文旅景区公告
3. 页面打不开 → scrapling stealthy-fetch 降级（scrapling skill）；突发（道路中断/景区关闭/塌方/泥石流实况）→ 置顶，带日期+来源
   - **通道可靠性（2026-09 实测）**：`nmc.cn/publish/mountainflood.html`、`yn12379.cn` 常年返回旧缓存/空壳（山洪页停在 9月8日），**不可作为当日依据**；省级地灾预警最快通道是新浪/腾讯转载的"云南气象"预警原文（搜索 `云南 地质灾害气象风险预警 <日期> 迪庆州`，原文出现"迪庆州中东部…Ⅲ级"即覆盖本区）；web_extract 无 key Parallel 通道易 30s 超时，重试或换 URL，别据此写"数据源不可用"

**Step 2.5 区域适用性闸门（硬规则，先判后写）**
每条预警/突发落笔前**必须先判是否覆盖本区**：
1. **覆盖本区**（点名迪庆/香格里拉/虎跳峡/三坝/哈巴，或"云南西部和北部/滇西北"含迪庆）→ 进预警区+级别色；大区表述须注明"含迪庆"
2. **相关但上游/边缘**（仅丽江市区、玉龙县）→ 可列，标 `ℹ️ 周边`，**不着色**，一句话说明间接意义
3. **不覆盖本区**（海南/西藏/四川/新疆等）→ **禁止进预警区、禁止上色**。默认整条省略；确需交代时末尾压一行 `ℹ️ 区域外预警 N 条（不含本区）已过滤`——**不写具体区域名，不写"云南已退出/前一日含滇西北"这类比较说明**
4. 全国性联合预警（地灾/山洪）**只提取点名云南/迪庆的部分**；不含本区按第 3 条
5. 覆盖与否**以发布单位原文文字为准**，不靠推测；无法确认时按"不覆盖"处理（宁缺不假警报）

**Step 3 高海拔-低海拔对比与上游产流**：高山降水>河谷（黑海/兰花坪/尖山牧场 3600-4200m 雨量大→上游产流→虎跳峡/哈巴村沟谷山洪泥石流风险升）；温差≈6.5℃/1000m；阵风 `gust_max_kmh`≥10级=橙级关注

**Step 4 线路评级**（🟢🟡🟠🔴，两线分开）
- 虎跳峡高路：临崖路+落石+强风+雨后滑坡，结合景区公告/道路管制
- 哈巴村-兰花坪-黑海-尖山牧场：高海拔+沟谷山洪+雷电+低温大风（最高黑海≈4200m，不涉雪线）
- 理由必须引用实际数据（预警/雨量/趋势/温度/海拔差），禁止空泛

**Step 5 输出**：结构规则+完整样例（有风险日/无风险日）见 references/output-template.md；无显著风险必写"当前未见显著气象/地灾风险信号"；末尾列来源清单

## 风险分级判据（四级，取两线路更高等级）

| 级别 | 判据 |
|:--|:--|
| 🟢 绿 | 无预警；24h<25mm 且未来3天无单日≥25mm；无≥10mm/h 信号；无地灾/山洪预警；无封路封景区 |
| 🟡 黄 | 蓝/黄色暴雨、雷电、大风预警；24h 25-50mm；未来48h 单日≥25mm 或≥10mm/h 可能；地灾/山洪蓝警或黄警；个别路段临时管制 |
| 🟠 橙 | 橙色暴雨/强对流预警或地灾/山洪橙警；24h 50-100mm；连续2日强降雨土壤饱和；高海拔降水显著大于低海拔；景区部分关闭或塌方处置中 |
| 🔴 红 | 红色预警（暴雨/山洪/地灾）；24h≥100mm；已发生道路中断/景区关闭/塌方/泥石流/山洪实况；上游强降水+下游土壤饱和叠加 |

国标：24h≥50mm=暴雨、≥100mm=大暴雨；1h≥20mm=短时强降水（简报提前用≥10mm/h提示）。
**判级只用覆盖本区的信号**——区域外预警不得作为升级依据。

## 颜色与警示符号使用规则（硬规则）

**总原则：颜色=风险信号。只在本区真有风险时着色，没风险一律中性。**

| 位置 | 规则 |
|:--|:--|
| 区块标题 | 固定中性 `📢 预警·突发`。**禁止把颜色写进标题**（旧版硬编码 🔴 是"无风险也报警"的根源） |
| 总评行 | 有风险 → 风险四色方块+一句话结论，**不叠 ⚠️**；无风险 → 🟢+✅ |
| 线路评级 | 四色方块，仅代表该线路当日风险等级 |
| 预警行 | 级别色（🔵蓝🟡黄🟠橙🔴红）**仅限覆盖本区且生效中的预警**；区域外/已过期 → 走 ℹ️，**不着色** |
| 无预警日 | 写"— 本区无生效预警"，**不写"— 无"、不加任何彩色/反色** |
| 符号语义 | ✅状态正常 ｜ ℹ️中性备注（区域外预警/历史事件）｜ ⚠️仅限本区实存风险 |

## 输出结构（决策优先，整体≤20行）

总评行置顶 → ① 线路评级 → ② 结论 → ③ 预警·突发（**≤4行，含 ✅ 状态行**）→ ④ 降雨要点（2行）→ ⑤ 温度·路线（**固定3行**）→ 📚 来源
- ③ 每条一行 `级别色｜类型｜发布方｜时间·时效｜影响区域≤30字`；无本区预警写"— 本区无生效预警"
- ⑤ 温度三行（v1.5）：**行1** 逐点位今日温区（虎跳峡镇1800m/哈巴村2700m/兰花坪3450m/黑海4150m + ℃范围）｜**行2** 未来3天趋势（河谷看白天、高海拔看夜间最低）｜**行3** 装备/体感提示（黑海夜间<5℃→羽绒+0℃标睡袋；给温差与清晨温度）。**格式与示例见 references/output-template.md §二**
- ⑤ 只报路线四点位，不报顶峰；香格里拉/丽江国家站官方预报只作锚点校验，偏差>3℃ 时注明"估算可信度下降"
- 时间只写「月-日 时:分」；来源压成机构名列表；飞书不渲染表格，用「｜」一行式，拒绝长段落
- 删除：点位逐日明细、预警原文长段、冗余链接、顶峰/雪线内容、多日重复的陈旧事件

## 注意事项

- **陈旧信息闸门**：静态/陈旧事件（景区复开通报、历史落石、封山通告、往年管制）只在①首次出现 ②状态变化 ③与当日风险直接相关 时播报，否则并入一行"无新通报"，**禁止多日原样重复**
- **温度规则**：一律用 `temp_est` 并标"估算"，**禁止直接用网格原值**（河谷点会低约 10℃）；温度不单独决定风险等级，但黑海/兰花坪夜间 <5℃ 或 <0℃ 必须在⑤给装备提示；`temp_est` 不可用时写"温度估算不可用"
- 发布超 24h 的预警标"已过期"；**过期预警不进预警区、不上色**
- 时间一律**北京时间**（禁止写 CST）；数据注明获取时间
- **双源原则**：网格(Open-Meteo)只做山区趋势/对比（山区无国家站），数值以官方站点实测+预警为准；矛盾时如实说明
- cron 模式下 terminal/execute_code 被拦截——数据只用 cron script 注入 + web_search/web_extract
