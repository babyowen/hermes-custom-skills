# 简报输出结构与样例（虎跳峡·哈巴雪山风险简报）

> v1.5 起 SKILL.md 只保留规则，完整样例在此。**颜色=风险信号，没风险不上色**；**不覆盖本区的预警一律不进预警区**（区域适用性闸门见 SKILL.md Step 2.5）；**温度只报 `temp_obs_corrected` 乡镇实况锚定校正值**（v1.6）。

## 一、六块结构（按阅读优先级）

1. **总评行**（置顶）：`风险色方块 + 【虎跳峡·哈巴雪山 风险简报】+ 日期（北京时间）+ 一句话定调`
2. **① 线路评级**：两条线路各一行 = 颜色 + 线路名 — 一句话理由（引用当日实际数据）
3. **② 结论**：一行，可执行；无风险日必写"当前未见显著气象/地灾风险信号"
4. **③ 预警·突发**：标题固定 `📢 预警·突发`；每条一行 `级别色｜类型｜发布方｜时间·时效｜影响区域≤30字`；无本区预警写"— 本区无生效预警"；**≤4 行（含 ℹ️ 过滤行与 ✅ 状态行）**
5. **④ 降雨要点**：两行——24h 高海拔vs低海拔对比、未来趋势
6. **⑤ 温度（路线，固定三行，v1.5）**：今日逐点位温区 → 未来3天趋势 → 装备/体感提示
7. **📚 来源**：机构名列表，压一行

整体 ≤20 行（含空行）；飞书不渲染表格，用「｜」一行式；时间只写「月-日 时:分」。

## 二、温度块规则（v1.6）

- **数据源**：只用 `temp_obs_corrected.points[*]`（乡镇自动站实况锚定校正值），标"实况锚定"；**不用网格原值**（河谷点低约10℃）、**不用固定直减率 `temp_est`**（河谷点高2~3℃）
- **必报四点位**：虎跳峡镇(1853m) / 哈巴村(2700m) / 兰花坪(3450m) / 黑海(4150m)；**不报顶峰、不报雪线**
- **锚点**：虎跳峡镇→本镇自动站(101291301003)；哈巴村→三坝乡站(101291301008)；兰花坪/黑海→建塘镇·香格里拉城区站(101291301004)。偏差与期望区间见 `anchors[*]` / `points[*].check`
- **行1 末尾必须括注实况锚点**：`（实况锚定：虎跳峡镇站 08:00 14.9℃）`——让人一眼看出数字来自实测而不是模式
- **不确定度**：`points[*].uncertainty_c > 0` 的点位在该点温度后加 `（不确定±N）`——来自两种算法（偏差校正 / 锚点实测按直减率外推）的差异，或锚点与目标点海拔差 >300m（当前：哈巴村 ±2、黑海 ±2；虎跳峡镇/兰花坪为 0）。明细见 `points[*].today_bracket`（两端各自的区间）
- **行2 趋势**取 `days[]` 未来3天 + `next3d_night_min_c`：河谷看白天高低温走向，高海拔看夜间最低走向
- **行3 装备提示**（决策优先，必须给结论）：黑海/兰花坪夜间 <5℃ → 羽绒+0℃标睡袋；<0℃ → 强调结冰/硬壳水汽；`windows_today_c.dawn_06_08` 是清晨出发体感；河谷-黑海温差用两点当日最高温相减
- **行4 口径**（手机天气质疑过、或官方乡镇预报与本镇实测差 >4℃ 时给一行）：`ℹ️ 口径｜实况锚定 虎跳峡镇站 08:00 14.9℃（该站过去24h实测 14.6~25.4℃）；手机天气"虎跳峡镇"= 香格里拉3280m 的县级数（官方乡镇预报 8~19℃），比河谷低 6~7℃`
- 温度**不单独决定风险等级**，但 `<0℃` 或强降温（日降 ≥3℃）要在 ⑤ 点名；`temp_obs_corrected.warnings[]` 非空必须在简报里交代
- 高海拔点由锚点站按直减率外推，锚点与目标点海拔差 >300m 时保留 ±2℃ 不确定度（勿给到小数点后一位的假精度）

## 七、发布时效处理

- 预警时效写明"·至今日20:00"这类**原文时效**；超过24h未更新的标注"**已过期**"
- **已过期/区域外预警不上色、不进预警区**
- 同一条预警连续日续发时，只在影响区域或级别变化处提示，不复制全套说明
- 温度块里若 `temp_est.available=false`（脚本缺高程/海拔）→ 写"温度估算不可用"，不要留空、不要拿网格原值顶
