# 飞书简报模板（图标化 · 扫读优先）

**版式原则**
1. 结论、关键动作放前 3 行——扫一眼就知道要不要管。
2. 每行 ≤1 个主题、≤~70 字；用 `｜` 分隔同级信息（飞书不支持 Markdown 表格）。
3. 图标只表达状态，不做装饰；同一含义全篇只用一个图标。
4. 正常项一行带过，异常项写清「什么 + 多少 + 建议动作 + 记录 ID」。
5. 全文 ≤15 行，200–400 字。

**图标字典（统一使用，不要混用）**

| 图标 | 含义 | 图标 | 含义 |
|:--|:--|:--|:--|
| 🟢 | 总体正常 | ✅ | 该检查项通过／未发现问题 |
| 🟡 | 总体关注 | ⚠️ | 需注意／疑点待核 |
| 🔴 | 总体异常 | ❌ | 已确认的问题 |
| ⛔ | 监测受阻 | ❔ | 数据不足，不可判断 |
| 📊 | 数据量 | 📈 / 📉 | 高于／低于基线 |
| 🏷️ | 主题分布 | ➖ | 与基线基本持平 |
| 🤖 | 模型评分 | 🔍 | 随机抽检 |
| 🌐 | 官网来源 | 📌 | 需要处理（最多 2 项） |
| 🧭 | 边界说明 | 🔁 | 同日重复检查且结论有更新 |

**模板**

```text
【serp_news 日巡检｜业务日期 YYYY-MM-DD】{🟢|🟡|🔴|⛔} {正常|关注|异常|监测受阻}
📊 数据：N 条 ｜ 较七日基线 {📈|📉|➖} X%（基线 A 条/天·V 天有效）｜ 高分 N 条
🏷️ 主题：K/8 有产出 ｜ {⚠️ 偏离或归零的主题：当日 N（基线 A）} ｜ 主力 {主题} N 条
🤖 模型：未评分 N ｜ 越界 N ｜ 均分 X（各档 5:N 4:N 3:N 2:N 1:N 0:N）｜ 摘要候选 N／完成 N {✅|⚠️}
🔍 抽检：N 条（M 主题·长文含摘要 N·低分 N）｜ {✅ 未发现摘要矛盾/无正文高分/报错|❌ 问题描述}
🌐 官网：{✅ 有，当日 N 条（id…）| ➖ 当日无抓取记录} ｜ 最近产出 YYYY-MM-DD
📌 需处理：① {问题＋记录 ID}；② {问题＋记录 ID}（没有就整行省略）
🧭 边界：依据数据库记录，未核验服务器执行日志（含上海官网任务）
```

**写法细则**
- 官网只报库内有无：有→「✅ 有，当日 N 条」，无→「➖ 当日无抓取记录」。**不访问官网页面、不写「疑似漏采」**（2026-09-19 用户确认）。
- 主题波动、量级异常要给**依据**（如过去 4 个同星期对比），没有依据不写因果猜测；能被工作日/周末解释时写明「量级同档，非突增」。
- 不可判断的指标用 `❔` 标注，不用 0%/100% 填充。
- 发现实质错误配一条简短原文对照证据，别只说「质量不好」。
- 同日重复检查且结论有变化时，第一行末尾加 `🔁 更新`。
- 不发送大段全文、整库数据、口令。

**发送**
```bash
lark-cli im +messages-send --chat-id "$FEISHU_HOME_CHANNEL" --as bot \
  --markdown "$(cat /tmp/serp_report_<D>.md)" \
  --idempotency-key "serp-news-check-<D>"
```
核对返回的 `ok:true` 与 `message_id`（`om_...`）后才说「已通知」；发送状态不明时不盲目重发（同一 `--idempotency-key` 可防重复）。

## 状态文件（去重）
`~/.hermes/cache/serp-news-monitor/<业务日期>.json`
```json
{"sent": true, "msg_id": "om_xxx", "verdict": "关注",
 "sample_ids": [143523, 143627], "extended_ids": [143636], "updated_at": "…"}
```
`msg_id` 只存最新一次发出的回执（旧回执放 `msg_id_history`），复跑时照它报回执，别引用历史 ID。

## 实例（2026-09-18 实跑）
```text
【serp_news 日巡检｜业务日期 2026-09-18】🟡 关注
📊 数据：372 条 ｜ 较七日基线 📈 +43%（基线 259.6 条/天 · 7 天有效）｜ 高分 82 条（基线 43.1）
🏷️ 主题：8/8 有产出 ｜ ⚠️ 公积金 61 条（基线 20.3）、机关事务 12 条（基线 2.0）超阈值，原因未核实 ｜ 主力 烟草服务银行 184 条
🤖 模型：未评分 0 ｜ 越界 0 ｜ 均分 2.67（5:61 4:20 3:145 2:44 1:82 0:19）｜ 摘要候选 226／完成 226 ✅
🔍 抽检：8 条（7 主题 · 长文含摘要 6 · 低分 2）｜ ✅ 未见摘要与正文矛盾、无正文/错误页拿高分、无报错输出
🌐 官网：✅ 有，当日 1 条（id=143508）｜ 最近产出 2026-09-18
📌 需处理：① 公积金/机关事务增量原因待核 ② id=143685 主题「烟草服务银行」下银行 AI 白皮书给 5 分，相关度偏弱，建议人工复核
🧭 边界：依据数据库记录，未核验服务器执行日志（含上海官网任务）
📈 量级解释：过去 4 个周五 337/354/350/233 条，当日同档，属工作日/周末差异
```
