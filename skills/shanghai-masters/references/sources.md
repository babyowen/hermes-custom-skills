## 二、抓取纪律（踩过的坑）

1. **同名赛事污染是第一大坑**：搜「上海大师赛」会同时命中 **网球 / 斯诺克 / 电竞 / 狼人杀（京城大师赛）**。`-斯诺克` 这类排除**无效**，必须结果后处理：
   - 黑名单（命中即丢）：`斯诺克 snooker 奥沙利文 丁俊晖 特鲁姆普 塞尔比 斯佳辉 国锦赛 台球 九球 剑网3 京城大师赛 狼人杀`
   - 电竞/赛车（命中即丢）：`手枪局 电竞 CS2 LPL 英雄联盟 王者荣耀 耐力赛 摩托 赛车`
   - 硬门槛：必须命中 `网球/大师赛/旗忠/劳力士/ATP` 之一
2. **`site:` 在 web_search 后端无效**（返回 0 条）。要 `site:` 走脚本里的 DDG。
3. **B站解析**：取 `bili-video-card__info--tit` 的 `title` 属性；抓 `<a>` 文本会得到播放量"664 0 02:30"。
4. **限流应对（百度/搜狗/DDG 通用）**：脚本期已压到「核心 2 组 + 轮换 1 组」+ DDG 固定预算 4 条查询。报限流时：**不要重试轰炸**（延长冷却）→ 改用 `web_search` 补一轮 → 连续 2 天以上才在报告里提一句。
5. **公众号/百度/DDG 返回的是跳转或带参链接**：报告里别承诺"点开就是原文"。
6. **抓不到 ≠ 不存在**：小红书实操攻略确实多，本技能只能拿标题/摘要 → 标「转述」。
7. **官方赛果页的两个坑（脚本已修，改脚本别踩回去）**：
   - **单打/双打混排，header 文案一模一样**（都是 `Men's Round of 32. Show Court 3`）→ 只能数**块内 name 节点数**：单打 2 个、双打 4 个（双打是每队一个 `stats-item` 内含两个 name）。数 `stats-item` 个数不管用（双打也是 2 个）。
   - **输的一方赢下一盘也带 `class="score-item won"`** → 胜者判定优先用 stats-note 的 `Game Set and Match <全名>.`，兜底才比 won 盘数。
   - 另：`?resultDay=1..14`，Day 1–2 是资格赛（`1st/2nd Round Qualifying`），抢七/退赛场的比分字段可能为空。

## 三、检索关键词

脚本内（`KEYWORD_SETS`）：核心组 **停车自驾 / 带物安检**（天天跑）+ 轮换组 **讨论热点 / 吃饭餐饮 / 观赛周边 / 赛况赔率**（每天 1 组）。每组 2 个词。

`web_search` 补充查询（每期 3–5 条，按当天维度倾斜）：
- `上海大师赛 停车 自驾 攻略 元江路 2026` ← 停车方案最值钱的一条
- `旗忠网球中心 停车 最近的马路 导航 哪个门`
- `上海大师赛 限带物品 清单 水杯 保温杯 能不能带` ← 直接回答用户问题
- `上海大师赛 安检 排队 入场 现场 实测`
- `上海大师赛 半决赛 决赛 对阵 预测` / `上海大师赛 冠军 赔率`
- `上海大师赛 现场 餐饮 纪念品 攻略`
- `上海大师赛 散场 堵车 几点走`
- `上海网球大师赛 小红书 攻略`（拿摘要，标转述）

**有效结果长什么样**：上海本地宝《2026上海劳力士大师赛交通出行攻略》给出「场内 P1/P2 只给持证车、观众停周边六区、10 元/车次免费 1 小时」；澎湃·闵行融媒 10/5 稿给出「共 4020 个泊位、由近及远分级开放、元江路（曙光路—中青路）设临时车位、中青路单侧近元江路 20 个即停即走点位」——这类**当地生活服务站/区级融媒的年度交通稿**是停车最佳来源，每年赛前 1–2 周发布，**优先检索它**。
